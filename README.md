# 💿 UNDERSKY ★ Official Y2K Music Hub

Sitio web oficial de promoción musical para **UNDERSKY** ([@skyogxx999 en SoundCloud](https://soundcloud.com/skyogxx999)) con estética auténtica **Y2K / Años 2000** (estilo Winamp, Windows 2000, marquesinas neón, CD holográfico interactivo y ecualizador visual).

---

## 🌟 Características

- **Diseño Vibes 2000s / Cyber-Retro**:
  - Ventana estilo Winamp con barra de título clásica y controles.
  - Pantalla LCD verde fósforo con ticker de audio y analizador de espectro (ecualizador animado).
  - Disco CD-ROM holográfico giratorio interactivo (haz clic para pausar/reanudar el giro).
  - Efecto de líneas de escaneo CRT (puedes activarlas o desactivarlas con el botón `CRT: ON/OFF`).
  - Gradientes cromados metálicos, bordes 3D bevel y paleta neón cyan, magenta y verde fósforo.
- **Detección Automática de Nuevos Lanzamientos**:
  - Cada vez que alguien entra a la web, el sistema consulta en tiempo real el perfil de SoundCloud de `@skyogxx999`.
  - Si detecta una nueva canción, actualiza inmediatamente el banner de **"¡NUEVO LANZAMIENTO!"**, la marquesina, el display LED y el botón de reproducción directa.
  - Si no hay conexión o el servicio de SoundCloud tarda, utiliza automáticamente la copia local optimizada para que la web nunca se quede en blanco ni tarde en cargar.
- **Reproductor Oficial Integrado**:
  - Widget embebido oficial de SoundCloud para que cualquier visitante pueda escuchar la música directamente desde la página.
- **Listo para Móviles y Computadoras**:
  - 100% responsivo, ligero y rápido sin dependencias pesadas.
